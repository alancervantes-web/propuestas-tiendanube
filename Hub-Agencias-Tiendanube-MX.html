Lo nuevo

Ya puedes ofrecer Lumi y Admin MCP

Nuevo

Lumi

La IA que viene dentro del administrador. En una implementación te ahorra horas de carga de catálogo.

  • Le pides un diagnóstico del negocio por texto, voz o imagen.
  • Escribe descripciones con SEO, crea imágenes y sube productos.

Antes de ofrecerlo, revisa que el cliente esté en un plan pago. Cada acción gasta créditos.

Nuevo

Admin MCP

El conector oficial para manejar la tienda desde Claude, ChatGPT o Gemini. También funciona en Cursor y VS Code.

  • Consulta y edita productos, órdenes, clientes y cupones desde el chat.
  • Haz cambios masivos o pide un reporte en segundos.

Si llevas varias tiendas, puedes operarlas desde una sola conversación.

2.2

Editor de plantillas

El tema base para tiendas a la medida. Se edita por secciones y es el único con desarrollo completo de código.

  • Armas la tienda con más de 15 secciones y bloques, sin código.
  • Cambias colores, tipografía y CSS por sección y ves el resultado antes de publicar.

Antes de cotizar, para editar layouts, secciones o bloques tienes que hacer fork del tema.

Para desarrollo, usa el CLI

Trabajas el tema desde tu editor de código. Este es el flujo:

tiendanube theme create --base-theme ipanema
tiendanube theme pull --theme-id ID
tiendanube theme fork
tiendanube theme watch
tiendanube theme publish

2.3

Mayoreo (B2B)

Menudeo y mayoreo en la misma tienda. El mayorista inicia sesión y ve sus propios precios.

  • Tablas de precios por catálogo, categoría o producto.
  • Pedido mínimo, pagos y envíos solo para mayoristas.
  • El mayorista se registra solo.

Antes de cotizar, revisa el plan. Funciona desde el plan Tiendanube, no en Gratis ni Básico.

¿Tu cliente tiene caso B2B?
  1. ¿Le vende a distribuidores o revendedores?
  2. ¿Toma pedidos de mayoreo por WhatsApp o Excel?
  3. ¿Maneja precios distintos por volumen?

Si contesta que sí a cualquiera, propónselo.
