2.2

Ipanema

El tema base para tiendas a la medida: todo es editable por secciones y es el único con desarrollo completo de código.

  • Más de 15 secciones y bloques, sin código.
  • Colores, tipografía y CSS por sección, con vista previa.
  • Desarrollo con el CLI desde tu editor.

Antes de cotizar: para editar layouts, secciones o bloques, haz fork del tema.

Ver flujo de desarrollo con el CLI 
tiendanube theme create --base-theme ipanema
tiendanube theme pull --theme-id ID
tiendanube theme fork
tiendanube theme watch
tiendanube theme publish

2.3

Ventas mayoristas (B2B)

Menudeo y mayoreo en una sola tienda: el mayorista inicia sesión y ve sus propios precios.

  • Tablas de precios por catálogo, categoría o producto.
  • Pedido mínimo, pagos y envíos exclusivos.
  • Autorregistro: el mayorista se da de alta solo.

Antes de cotizar: disponible desde el plan Tiendanube; no aplica en Gratis ni Básico.

¿Tu cliente tiene caso B2B?
  1. ¿Le vende a distribuidores o revendedores?
  2. ¿Toma pedidos de mayoreo por WhatsApp o Excel?
  3. ¿Maneja precios distintos por volumen?

Un “sí” basta para proponerlo.

Lumi trabaja dentro del administrador; Admin MCP lleva la tienda a tu IA.

Nuevo

Lumi

La IA del administrador: analiza la tienda y ejecuta tareas por el comerciante.

  • Diagnóstico del negocio por texto, voz o imagen.
  • Descripciones SEO, imágenes y carga de catálogo.
  • Incluido en planes pagos; las acciones usan créditos.

Para tu agencia: acelera implementaciones y suma valor en la entrega.

Guías de Lumi Ayuda Qué es Lumi Blog
Nuevo

Admin MCP

Gestiona la tienda desde Claude, ChatGPT o Gemini, sin entrar al administrador.

  • Productos, órdenes, clientes y cupones por chat.
  • Cambios masivos y reportes en segundos.
  • Conector oficial; también funciona con Cursor y VS Code.

Para tu agencia: opera varias tiendas desde una sola conversación.
